## Date - 2026-09-02 
Setting up SG-restricted SSH access to app_server instance

## ERROR: 
ssh: connect to host <ip> port 22: Connection timed out → later: Permission denied (publickey,gssapi-keyex,gssapi-with-mic)

## TRIED: 
Verified SG rules, 

route table,
NACLs, 

IGW attachment,

instance status, 

subnet placement — all correct.

Ruled out local network via `ssh -T git@github.com` (succeeded). Compared local key vs AWS-registered key (matched).

## FIX: 

Two separate root causes, sequential — 

(1) dynamic ISP IP had rotated past what was in the SG's SSH CIDR rule, causing the timeout; re-checked `curl -4 ifconfig.me` and reapplied SG with current IP. 

(2) `key_name` variable was declared in the module but never referenced in the `aws_instance` resource, nor passed from the root module call — instance had no key attached at all, causing the auth failure once networking was fixed. Wired `key_name` through both files, forced replacement, connected successfully.
